Sales Trend Visualization Dashboard

Project Overview

This project presents an interactive Sales Trend Visualization Dashboard developed using Microsoft Power BI. It helps analyze sales performance, profit, product trends, and sales patterns through interactive charts and visualizations.

Objectives

- Analyze overall sales and profit performance.
- Identify sales trends over time.
- Compare sales across different product categories.
- Understand product-wise sales performance.
- Present business data in an easy-to-understand visual format.

Tools and Technologies

- Microsoft Power BI
- Power Query
- Data Visualization
- Microsoft Excel (source data preparation)

Dashboard Features

- Total Sales KPI
- Total Profit KPI
- Sales and Profit Analysis
- Monthly Sales Trends
- Product-wise Sales Visualization
- Category-wise Sales Analysis
- Payment Mode Analysis
- Interactive Filters and Charts
